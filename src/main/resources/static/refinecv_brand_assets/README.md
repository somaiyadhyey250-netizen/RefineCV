# RefineCV Brand Assets

Primary visual identity:
- Gradient: #0EA5FF → #8B5CF6 → #22D3EE
- Dark background: #070B14
- Secondary dark: #081220
- Font recommendation: Inter (fallback: Plus Jakarta Sans, Arial, sans-serif)
- Product descriptor: RESUME INTELLIGENCE
- Tagline: Analyze · Understand · Improve · Grow

## Recommended web usage

### Navbar / header
Use:
- `svg/refinecv-logo-dark.svg` on dark backgrounds
- `svg/refinecv-logo-light.svg` on light backgrounds

### Footer / monochrome situations
Use:
- `svg/refinecv-logo-black.svg`
- `svg/refinecv-logo-white.svg`

### App icon / favicon
Use:
- `favicon/favicon.ico`
- `favicon/favicon-32x32.png`
- `favicon/favicon-16x16.png`
- `favicon/apple-touch-icon.png`
- `favicon/android-chrome-512x512.png`
- `svg/refinecv-favicon.svg`

### Compact UI / mobile
Use:
- `svg/refinecv-mark-gradient.svg`
- `svg/refinecv-mark-black.svg`
- `svg/refinecv-mark-white.svg`

### Social sharing / Open Graph
Use:
- `png/refinecv-og-1200x630.png`

## Important
The SVG files are the primary web assets. Prefer SVG on the website because they remain sharp at any resolution.
Do not recreate the logo with CSS or substitute a text-only "R" icon.
